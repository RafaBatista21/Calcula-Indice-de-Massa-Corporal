# ⚖️ Calculadora de Índice de Massa Corporal (IMC)

Este projeto é uma aplicação web simples que permite adicionar pacientes em uma lista e calcular automaticamente o IMC (Índice de Massa Corporal) de cada um. Foi desenvolvido com foco em praticar HTML, CSS e JavaScript, e reforçar a lógica de manipulação do DOM.

---

## 🚀 Tecnologias utilizadas

- ✔️ HTML5  
- ✔️ CSS3  
- ✔️ JavaScript (puro)

---

## 🎯 Funcionalidades

- ✅ Adição de pacientes em uma lista  
- ✅ Cálculo automático do IMC para cada paciente  
- ✅ Validação de dados de entrada  
- ✅ Exibição dos dados de forma visual no navegador

---

## 🖥️ Interface

- Desenvolvida com HTML e estilizada com CSS  
- Interações e lógica implementadas com JavaScript puro  
- Projeto totalmente **front-end**

---

## 🗃️ Banco de dados

- ❌ Este projeto **não utiliza banco de dados**

---

## 📦 Como executar o projeto

1. Clone o repositório:

```
git clone https://github.com/RafaBatista21/Calcula-Indice-de-Massa-Corporal.git
```

2. Acesse o diretório:

```
cd Calcula-Indice-de-Massa-Corporal
```

3. Abra o arquivo `index.html` no navegador de sua preferência.
